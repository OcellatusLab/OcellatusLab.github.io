Política de privacidade

Este site não coleta dados pessoais. Ele não tem formulários, não usa cookies, não carrega scripts de terceiros e não usa ferramentas de análise de audiência ou de publicidade.

O que acontece quando você visita o site

O site é um conjunto de páginas estáticas hospedado no GitHub Pages, serviço do GitHub, Inc. Como qualquer servidor web, o GitHub pode registrar dados técnicos da conexão, como o endereço IP, para fins de segurança e operação do serviço. A Ocellatus não tem acesso a esses registros. Veja a declaração de privacidade do GitHub.

Quando você entra em contato

Os botões de contato abrem o seu aplicativo de WhatsApp ou de e-mail. Nada é enviado pelo site. As informações que você decidir compartilhar nessas conversas são usadas só para responder ao seu contato e, se for o caso, preparar uma proposta. Elas não são vendidas nem repassadas a terceiros.

Seus direitos

Pela Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você pode pedir confirmação, acesso, correção ou exclusão dos dados que tenha enviado à Ocellatus em um contato. Basta escrever para PREENCHER_EMAIL.

Segurança

Encontrou uma vulnerabilidade neste site? As instruções estão em /.well-known/security.txt.
